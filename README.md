# Yuddha.Pro design pack

Yuddha.Pro design pack: dark arcade shell, emblem B, pieces, board spec, flow map.

**Start here: [SUPERGROK-START-HERE.md](SUPERGROK-START-HERE.md)**

## Contents

- `dark-v1/shell-C-full/`: chosen direction, the dark arcade game shell (27 screens + overview)
- `dark-v1/emblem-B-final/`: chosen Yuddha emblem B ("Liyawela Filigree") and intro sequence
- `dark-v1/00-board-spec.png` + `dark-v1/board-spec.md`: board themes and interaction spec
- `dark-v1/00-flow-map.png` + `flow-spec.md` files: app flow map and spec
- `dark-v1/00-icons.png`: icon set
- `pieces-v1/` + `v1-polish2/piece-sheet.png`: locked chess pieces
- `isadora/`: locked character art for Isadora Mandodhari (see `isadora/README.md`)
